# Easy Cooldown Glow

## English

> Glow the action bar buttons of spells enabled in Blizzard's Cooldown Manager (Essential cooldowns) when their cooldown finishes, so your big cooldowns are easy to spot at a glance.

- Only spells you actually enabled in Blizzard's Cooldown Manager (Essential cooldowns) are tracked; removing a spell from the manager removes its glow.
- Configurable glow duration when a cooldown finishes: none / 1-5 seconds / persistent (stays lit until the spell is used again).
- Works during combat, in and out. The original Cooldown Manager display is left untouched (nothing hidden or moved).
- A single settings page, built into Blizzard's own add-on settings; no slash commands.
- Settings can only be changed out of combat; the settings page is locked during combat.

## 简体中文

> 暴雪冷却管理器（主冷却）中已启用的技能，冷却完成后在对应动作条按钮上发光提醒，一眼看清哪些大招可用。

- 只追踪你在暴雪冷却管理器「主冷却」分组里实际启用的技能；从管理器中移除的技能不再发光。
- 冷却完成后的发光时长可配置：无 / 1-5 秒 / 持续（常亮到该技能再次被打出去为止）。
- 战斗内外均生效。冷却管理器原本的显示保持原样，不会被隐藏或移动。
- 只有一个设置界面，集成在暴雪自带的插件设置里；不使用斜杠命令。
- 设置需在战斗外修改；战斗中设置页会被锁定。

## 繁體中文

> 暴雪冷卻管理器（主冷卻）中已啟用的技能，冷卻完成後在對應快捷列按鈕上發光提醒，一眼看清哪些大招可用。

- 只追蹤你在暴雪冷卻管理器「主冷卻」分組裡實際啟用的技能；從管理器中移除的技能不再發光。
- 冷卻完成後的發光時長可設定：無 / 1-5 秒 / 持續（常亮到該技能再次被打出去為止）。
- 戰鬥內外均生效。冷卻管理器原本的顯示維持原樣，不會被隱藏或移動。
- 只有一個設定介面，整合在暴雪內建的插件設定中；不使用斜線指令。
- 設定需在戰鬥外修改；戰鬥中設定頁面會被鎖定。
